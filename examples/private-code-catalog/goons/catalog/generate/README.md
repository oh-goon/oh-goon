# catalog/generate

Generate a Backstage Component descriptor from reviewed, allowlisted metadata using the independent generator/ Python application. The app does not inspect, parse or copy the registered repository's source; Hashmarks and native Git own the upstream discovery facts.

The sole Step produces a retained catalog-info.yaml through the original Oh-Goon Plan/Goon/Fleet/Step lifecycle. The README at ../../../README.md gives the full no-provider local walkthrough and export instructions.
