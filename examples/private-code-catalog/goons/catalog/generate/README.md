# catalog/generate

Forward explicitly reviewed `candidate_json` to the shipped
`general/catalog-render` Python Goon. The shared standalone formatter supplies
both the guided UI preview and native generation; this example owns no copy of it.
It does not inspect repository source, Git or CODEOWNERS.

The sole Step produces a retained catalog-info.yaml through the original Oh-Goon Plan/Goon/Fleet/Step lifecycle. The README at ../../../README.md gives the full no-provider local walkthrough and export instructions.
